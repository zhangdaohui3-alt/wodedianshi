# 云端家长远程时间锁（2.47 测试模块）

本模块新增在 `ParentRemoteLockManager.java`，与直播播放器、频道换源和点播逻辑分离。主界面只负责生命周期、全屏密码窗口和按键拦截。

## 1. 在哪里填写云端接口地址

在电视 App 中进入：**设置与管理 → 云端家长锁设置**

填写你的 HTTPS 配置接口，例如 `https://example.com/api/parent-lock`。保存后 App 会立即请求一次，此后每 40 秒请求一次。留空并保存可关闭云端家长锁。

也可以在本地私有 SharedPreferences 中设置：文件 `mytv_remote_parent_lock`，键 `endpoint` 和 `remote_enabled`。

不要把真实管理员密码写入源码、GitHub 或调试日志。

## 2. GET 配置接口

App 使用 HTTPS GET 请求接口，服务端返回 `200 application/json`。推荐响应：

```json
{
  "lock_enable": true,
  "start_time": "08:00",
  "end_time": "21:30",
  "max_day_minute": 180,
  "offline_strict": false,
  "admin_pwd": "请替换为管理员设置的强密码",
  "server_time_ms": 1794200000000
}
```

字段说明：
- `lock_enable`：总开关。false 表示关闭云端时间限制。
- `start_time` / `end_time`：每日允许使用时间，支持跨午夜，例如 22:00–06:00。
- `max_day_minute`：每日最大前台观看分钟数；0 表示不限制。
- `offline_strict`：true 断网锁定；false 按上次缓存规则继续。
- `admin_pwd`：管理员数字密码，4–32 位；仅经 HTTPS 下发。
- `server_time_ms`：服务端当前 Unix 毫秒时间戳，强烈建议提供，用于校验系统时间跳变。

`start_time == end_time` 定义为全天允许（仍受每日最大时长限制）。开始时刻包含，结束时刻不包含。

## 3. POST 离线时长上报

联网恢复并成功拉取配置后，App 会向同一个接口 URL 发送 JSON POST。服务端应接受：

```json
{
  "device_id": "设备随机生成的UUID",
  "offline_usage_ms": 7200000,
  "usage_day": "2026-313",
  "client_time_ms": 1794200000000
}
```

返回任意 2xx 表示接收成功；App 才会清零待上报累计值。非 2xx 或网络失败会保留待上报时长，后续重试。服务端应按 `device_id` 和请求幂等处理，避免重复记账。当前上报的是离线期间累计的总毫秒数，`usage_day` 是当前本地日期标记。

## 4. 离线策略

- 宽松（`offline_strict=false`）：断网后读取上次成功获取的加密配置，继续执行允许时段和每日时长限制；不能接收云端新命令。
- 严格（`offline_strict=true`）：检测到断网后锁定，输入缓存配置中的管理员密码可临时解锁 15 分钟；期间仍会本地累计实际前台使用时间。
- 如果启用了云端锁但从未成功获取过配置，采用失败关闭策略：锁定，直到恢复联网并取得有效配置。

配置 JSON 使用 Android Keystore 中的 AES-GCM 密钥加密后保存到 App 私有 SharedPreferences。密码不写入普通明文偏好项，也不会写入日志。清除 App 数据或卸载后需要重新联网拉取配置。

## 5. 时间与观看时长

- 使用 `SystemClock.elapsedRealtime()` 计算经过时间，避免单纯依赖系统墙上时钟。
- 同时保存最近一次网络时间锚点；系统时间与单调时钟推算时间偏差超过 2 分钟时触发安全锁定。
- 推荐服务端始终返回 `server_time_ms`。若设备重启后系统时间被改动，必须有服务端时间才能可靠判断。
- 每 10 秒检查网络和锁状态；每 10 秒记录前台未锁定使用时长；每 40 秒拉取配置。
- 仅统计 App 在前台且未锁定的时间；锁定画面本身不计入观看时长。

## 6. 电视遥控器、手机和 HOME 键限制

- 锁定窗口为全屏黑色窗口，只有数字密码输入框；不提供关闭按钮，触摸外部不能关闭。
- 输入密码后按遥控器确认/Enter，或手机键盘完成键提交。
- 锁定期间 App 窗口收到的按键由 Activity 消费，Back 不会退出锁界面。
- Android 系统 HOME 键是系统保留按键，普通第三方 App 无权保证拦截。用户按 HOME 可能暂时离开 App；重新回到 App 时会重新检查并显示锁界面。
- 若要求真正 kiosk 级别的 HOME/最近任务限制，需要设备管理员在支持的机顶盒上预先将 App 配置为 Device Owner，并使用 Lock Task Mode。此操作通常需要设备初始化/ADB 或厂商管理能力，不能由普通 App 静默开启，也不保证每个当贝固件都支持。

## 7. 日志

过滤 Android 日志标签 `MyTVRemoteLock`。会记录联网/断网、配置获取、缓存读取/保存、锁定原因、时长累计和离线上报结果，不会打印密码或完整接口 URL。

## 8. 重要部署提醒

1. 必须部署真实 HTTPS 服务端；本次仓库改动只提供 Android 客户端模块，不会自动生成或托管云端服务器。
2. 示例密码仅为格式示意，部署时替换成管理员自己的密码；建议 6 位以上且避免弱口令。
3. HTTPS 证书必须由设备信任；不要使用自签名证书绕过校验。
4. 云端服务端必须鉴权设备并限制配置接口访问；生产环境建议每台设备独立令牌、配置签名/版本号、请求限流和审计。
5. 目前客户端在同一 URL 使用 GET 拉取、POST 上报。若你的服务器将上报设计为独立路径，需再增加 `usage_url` 配置字段并修改客户端。
6. 这版 APK 必须在当贝盒子和 Android 手机分别实测；GitHub 构建通过不代表所有遥控器固件和系统 HOME 行为均已验证。
